# Me’raj International School Maiduguri — GitHub Pages Demo

## Publish on GitHub
1. Create a new GitHub repository, e.g. `meraj-international-school`.
2. Upload everything in this ZIP to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Open the GitHub Pages URL after deployment finishes.

## Test the no-code workflow
Open `/admin.html`. You can test logo and gallery uploads. In a static GitHub demo, uploads are stored in browser local storage only; they do not become permanent files in the GitHub repository.

## Hostinger phase
After the design is approved, connect the frontend to the PHP/database CMS for permanent logo, gallery, video, audio and admission management. The frontend does not need to be redesigned from scratch.
